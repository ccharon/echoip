# Security policy

## Supported versions

Only the latest release, and the `latest` image built from it, receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately. Use GitHub's "Report a vulnerability" (Security tab, Advisories) at https://github.com/ccharon/echoip/security/advisories/new.

Do not open a public issue or pull request for a vulnerability.

Please include:

- what is affected and the version or image tag
- steps to reproduce, or a proof of concept
- the impact you expect
